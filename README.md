# PRISM — Vision-Based Gesture Control System 

**PRISM (Personal Recognition & Interaction System for Mobility)** is an experimental computer-vision project that allows users to control their desktop using hand gestures detected through a webcam.

Built with **Python, OpenCV, and MediaPipe**, PRISM tracks hand landmarks in real time, analyzes hand movement across video frames, recognizes gestures such as directional swipes, and translates them into computer commands.

The project is being developed incrementally, with the long-term goal of creating a customizable, multimodal desktop assistant combining **gesture recognition, voice commands, and real-time voice feedback**.

## Current Features

* Real-time webcam input using OpenCV
* Hand detection and 21-point hand landmark tracking using MediaPipe
* Frame-based hand movement analysis
* Directional swipe recognition
* Gesture state management to prevent repeated triggers
* Gesture-to-Windows command execution
* Customizable gesture command architecture

## Technology Stack

* **Python**
* **OpenCV**
* **MediaPipe**
* **Windows / PowerShell**
* **Webcam-based computer vision**

## Planned Features

PRISM is being developed as a long-term project. Planned capabilities include:

* Up and down gesture recognition
* Multiple hand gestures
* Fist and open-palm recognition
* Pinch gestures
* Advanced window management
* Volume and media controls
* Voice command recognition
* Real-time voice feedback
* Multimodal gesture + voice commands
* User-configurable gesture mappings
* Automatic startup initialization
* Gesture recognition accuracy and performance analysis

The system is intentionally being built in separate layers so that new gestures, commands, and interaction methods can be added without rewriting the entire application.

Long-Term Vision

The goal of PRISM is to evolve from a simple gesture controller into a **personal multimodal human-computer interface** capable of understanding gestures and voice commands and responding to the user in real time.

The project is also being developed as an exploration of **computer vision, human-computer interaction, automation, and artificial intelligence**.
